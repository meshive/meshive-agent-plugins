# Meshive for Claude Code

Use this plugin to compare GPU rental prices on Meshive and check the pods in your workspaces from Claude Code.

Ask “Which GPUs can I rent on Meshive, and what do they cost per hour?” to see public prices without signing in.

To check your own resources, ask “List the pods in my Meshive workspaces.” Where OAuth is enabled, follow the Meshive sign-in prompt, approve read access in your browser, then ask again. You can check the server connection at any time with `/mcp`.

For the full tool reference and manual access token setup, see the [Meshive MCP guide](https://docs.meshive.ai/sdk-cli/mcp/).
